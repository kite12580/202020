# capsule-bar

capsule-bar 用一个浮动、半透明、可拖动的胶囊条替代 Windows 11 底部任务栏。原生任务栏会被隐藏，最大化的窗口可以铺满整个屏幕。

```
╭──────────────────────────────────────────╮
│ ::  C  C  V [T] E  ^ W Q  中 <)  2:32 PM │
│                                 11/01/26 │
╰──────────────────────────────────────────╯
```

| 区域 | 操作 |
|---|---|
| `::` 拖动柄 | 拖动可移动位置（位置会被记住）；右键打开菜单：打开配置文件、重新加载配置、退出 |
| 窗口图标 | 每个窗口一个图标。左键：激活窗口，已在前台时最小化；中键：关闭；右键：系统菜单；悬停：显示标题 |
| `Win+1` … `Win+0` | 激活（或最小化）第 1 … 10 个窗口；加 `Shift` 新开一个实例，加 `Ctrl+Shift` 以管理员身份新开。`--safe` 下交给原生任务栏处理 |
| `^` | 弹出所有托盘图标。在弹窗里右键图标可以固定到胶囊条或取消固定 |
| 固定的托盘图标 | 点击、双击、右键的行为与原生任务栏相同 |
| 键盘布局 | 显示当前布局（中 / EN …）；中文输入法切到英文模式时显示“英”。点击后可切换布局 |
| 音量 | 滚轮调节音量，点击打开系统快速设置（同 `Win+A`），悬停显示百分比 |
| 时间 | 上行 12 小时制时间，下行日期（月/日/年）。点击打开通知中心和日历（同 `Win+N`），悬停显示完整日期和星期 |

前台程序全屏（游戏、F11、全屏视频、PPT 放映）时，胶囊条会自动隐藏。

只支持最新版 Windows 11，单显示器。

## 构建（在 Linux 上交叉编译）

```sh
rustup target add x86_64-pc-windows-msvc
cargo install --locked cargo-xwin
scripts/build.sh      # 生成 target/x86_64-pc-windows-msvc/release/capsule-bar.exe
scripts/check.sh      # 依次运行 fmt、clippy、core 测试、构建和产物检查
```

生成的 exe 静态链接了 CRT，不需要安装 VC++ 运行库。

## 运行

直接运行 `capsule-bar.exe` 即可。程序是便携版：配置和日志都放在 exe 所在的文件夹里，不写 AppData，所以请放在有写权限的目录。程序不会开机自启。

| 参数 | 作用 |
|---|---|
| `--safe` | 不隐藏原生任务栏，适合初次测试 |
| `--verbose` | 输出调试日志 |
| `--diag` | 在 `--verbose` 的基础上，额外记录窗口过滤的判定原因 |
| `--restore` | 恢复原生任务栏（用于主进程和守护进程都被强制结束之后） |

紧急退出快捷键：`Ctrl+Alt+Shift+Q`。

主程序会启动一个 `--watchdog` 子进程。主进程意外退出时，它会把任务栏的自动隐藏状态、可见性和工作区恢复原样。注意：如果在任务管理器里用"结束进程树"，守护进程也会一起被结束，这时请手动运行 `capsule-bar.exe --restore`，或者在设置里关闭"自动隐藏任务栏"。

## 配置

配置文件是 exe 旁边的 `config.toml`，首次运行时自动生成，修改保存后立即生效。各项说明见文件内的注释。如果亚克力效果失效（例如窗口一直是纯色），可以把 `backdrop` 改成 `"accent"`。

日志位于 exe 旁边的 `logs\log.txt`。反馈问题时请附上这个文件，最好是用 `--diag` 运行后得到的日志。

## 已知限制

- Windows 11 的系统托盘图标（网络、电池、系统音量）不经过 `Shell_NotifyIcon`，因此不会显示。
- 托盘图标通过 `TaskbarCreated` 广播重新注册。忽略这个广播的程序，要重启后它的图标才会出现。
- 同一种语言的两个输入法（比如拼音和五笔）在布局菜单里显示为同一个名称。
- 只有开启"滚动非活动窗口"（Windows 默认开启）时，滚轮才能调节音量。
